# Shortcut

|Shortcut key|Description|
|--|--|
|`Ctrl+L`|choose model|
|`Ctrl+P`|cycle model|
|`Shift-Tab`|thinking model|
|`Ctrl+G`|external editor|
|`Ctrl+-`|undo editor text|
|`Enter`|submit or steer|
|`Alt+Enter`|follow-up|
|`Escape`|abort|
|`Alt+Up`|dequeue|
|`/settings`|common config|
|`/login`|add apikey or login|
|`/reload`|reload pi session|
